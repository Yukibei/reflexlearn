## 二、AI 导师（重点，本轮改动最大）

进 `/chat`，依次输入下面四句，**注意每句的响应速度差异**——这是本轮核心改动。

### 2.1 寒暄 → 应当秒回

```
你好呀
```

预期：**0 秒**回复自我介绍，不生成任何资源、不创建学习目标。
再试试 `谢谢`、`嗯`、`在吗` —— 应该都是同样的快速回应。

### 2.2 学术问答 → 应当十几秒给出真答案

```
什么是梯度下降？它和随机梯度下降有什么区别
```

预期：**5–20 秒**给出一段真实讲解（有例子、有对比），可能结尾附一句针对你薄弱点的复习建议。
**不应该**生成 6 个资源，**不应该**新建学习目标。

再试一个：

```
这道题为什么要用洛必达法则
```

### 2.3 范围外请求 → 应当礼貌拒绝

```
帮我写一封辞职信，语气客气一点
```

预期：**3–8 秒**回复"我是专注学习的导师，只处理学科与学习相关的问题"。

### 2.4 学习方案 → 走完整多智能体链路

```
我想系统学习傅里叶变换
```

预期时间轴（**这是最需要你反馈体感的一项**）：

| 时间 | 现象 |
|---|---|
| 0–1 秒 | 出现思考过程：识别意图 → 画像构建 |
| 约 30 秒 | 规划完成，**开始逐字吐出第一份资源**（本轮修复的就是这里，之前是白屏干等） |
| 30 秒–4 分钟 | 资源逐个生成，思考过程持续更新 |
| 约 4–5 分钟 | 全部完成，出现学习路径，自动保存为学习目标 |

**关注点**：31 秒才出第一个字、总共要 4–5 分钟，这个等待你能否接受？逐字输出的过程是否让等待感变好了？

## 四、资源发现（/resources）

```
CSS Flexbox 弹性布局
```

预期：几秒内返回**真实的 B 站视频**（标题像真实 UP 主的视频）和**真实的 MDN 文档条目**。
