# 评测与复现

本文记录 ReflexLearn 当前评测入口、已验证结果、复现命令和已知限制。数字用于说明评测链路可以运行，不代表在扩大样本前的最终研究结论。

## 评测入口

| 入口 | 用途 |
| --- | --- |
| `scripts/run_eval.sh` | smoke、受控 RAG、受控 Reflexion 和元认知对比 |
| `scripts/run_real_eval.sh` | 连接真实 RAG / LLM 服务的评测 |
| `scripts/test_unit.sh` | 单元测试 |
| `scripts/check_llm.sh` | OpenAI-compatible 网关连通性和 JSON 输出检查 |

所有运行、调试和测试优先通过 `scripts/` 下的脚本完成；报告默认写入 `logs/`，不会把密钥写入输出。

## 最小复现

```bash
cp .env.example .env
bash scripts/test_unit.sh
bash -n scripts/*.sh
bash scripts/run_eval.sh --compare --tags ablation,rag_required \
  --strategies controlled_rag,single_agent_baseline --max-cases 1 --timeout 45
```

## 真实 RAG 对比

需要有效的 LLM key、Qdrant / Redis 等服务和已初始化的知识集合：

```bash
bash scripts/run_real_eval.sh --tags ablation,rag_required \
  --strategies real_full,real_no_rag,single_agent_baseline \
  --max-cases 1 --timeout 180
```

## 受控消融

```bash
bash scripts/run_eval.sh --compare --tags ablation,rag_required \
  --strategies no_rag,controlled_rag,single_agent_baseline --max-cases 1 --timeout 12

bash scripts/run_eval.sh --compare --tags ablation,reflexion_required \
  --strategies no_reflexion,controlled_reflexion,single_agent_baseline --max-cases 1 --timeout 12
```

受控策略注入固定参考上下文或失败经验，用于验证评分链路和理论上限，不等价于真实线上召回效果。

## 指标定义

- `resource_coverage`：生成资源类型覆盖 case 期望类型的比例。
- `correctness`：生成内容覆盖 reference concepts 的比例。
- `profile_match`：资源难度与 case 难度区间的匹配度。
- `completeness`：内容长度和目标覆盖的规则评分。
- `format_quality`：Markdown、题目答案和代码块等格式评分。
- `overall`：`correctness × 0.35 + profile_match × 0.20 + completeness × 0.30 + format_quality × 0.15`。

## 当前限制

1. 真实 RAG 目前只覆盖小样本，必须扩大 case 并进行人工抽检。
2. LLM Judge 在 key 不可用或输出异常时会降级为规则 Judge，报告会标记来源。
3. `real_full` 依赖 Qdrant、Redis、LLM 网关等外部服务，不应在服务不可用时宣称真实效果。
4. 受控 RAG / Reflexion 只证明评测设计和能力上限，不代表生产链路收益。
5. 评测结果会受模型版本、提示词、数据集、超时和中间件状态影响，比较时需固定环境。
